## 3. Performance Improvement Opportunities

### 3.1 Favicon Asset Size (Medium Severity)
- **Problem:** `public/favicon.ico` is **285 KB**.
- **Root Cause:** The `.ico` file contains four uncompressed 32-bit bitmaps (including 48x48 and potentially 128x128/256x256 uncompressed icons).
- **Impact:** Browsers automatically download `/favicon.ico` on initial page load, adding 285 KB of unnecessary transfer overhead to the critical rendering path.
- **Solution:** Re-generate `favicon.ico` with optimized 16x16 and 32x32 PNG compression (< 20 KB), and provide an SVG vector favicon `<link rel="icon" type="image/svg+xml" href="/logo.svg">` for modern browsers.

### 3.2 LCP Image Prioritization (Low Severity)
- **Problem:** The author headshot (`aritro-saha.webp`) on the homepage is the primary hero visual element above the fold, but lacks `fetchpriority="high"`.
- **Solution:** Add `fetchpriority="high"` to the hero `<img>` tag in `index.html` and `src/components/Header.jsx` / `src/components/About.jsx` to signal immediate download priority to browser preload scanners.
